# Demo Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a same-origin `/demo` web dashboard that exercises the backend APIs already implemented in this NestJS application.

**Architecture:** Serve static demo files from the existing NestJS app. A focused `DemoController` returns `public/demo/index.html`, while `main.ts` exposes `public/demo/assets` under `/demo-assets` and the installed Socket.IO browser client under `/socket.io-client`.

**Tech Stack:** NestJS, TypeScript, Express static assets, plain HTML/CSS/JavaScript, Socket.IO browser client.

---

- [ ] **Step 3: Implement module and controller**

Create `src/demo/demo.controller.ts`:

```ts
import { Controller, Get, Res } from '@nestjs/common';
import type { Response } from 'express';
import { join } from 'path';

@Controller('demo')
export class DemoController {
  @Get()
  index(@Res() response: Response): void {
    response.sendFile(join(process.cwd(), 'public', 'demo', 'index.html'));
  }
}
```

Create `src/demo/demo.module.ts`:

```ts
import { Module } from '@nestjs/common';
import { DemoController } from './demo.controller';

@Module({
  controllers: [DemoController],
})
export class DemoModule {}
```

Modify `src/app.module.ts` to import `DemoModule` and add it to the module imports.

- [ ] **Step 4: Run test to verify it passes**

Run: `npm test -- demo.controller.spec.ts`

Expected: PASS.
